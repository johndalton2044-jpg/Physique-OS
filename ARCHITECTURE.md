# PHYSIQUE OS — architecture

## Layers
1. **OBSERVATION** (`30-observations`): append-only records `{id,type,date,value,unit,method,source,quality,phaseId,supersedes,correctedBy,retracted,createdAt,flags}`. Corrections supersede; retractions keep the record. Every read takes an as-of date (`_ASOF`) so replay sees only records dated and created on or before that day.
2. **STATE** (`40-models` → `getCurrentState()`): rolling averages, Theil–Sen weight trend with residual noise and confidence, water-noise probability, circumference body composition, waist trend, fat-vs-other split, rate bands by weight zone, goal trajectory, training (e1RM consensus, strength trend, volume, consistency), recovery, appetite, adherence per stream, data trust, muscle-retention risk, step baseline/compensation.
3. **MODEL** (`40-models`): registry `MODELS[]` — class, version, inputs, minimum evidence, assumptions, failure modes. Below minimum evidence every model returns `{status:'insufficient', need:[…]}`, never a number. Energy model path: PRIOR (Mifflin-St Jeor × activity) → BLENDED (w = n/(n+14)) → EMPIRICAL (≥21 logged days at ≥75% coverage) → CALIBRATED (outcome adjustment from ≥3 scored 14-day forecasts).
4. **DECISION** (`50-decision`): `diagnose()` ranks findings (stall, slow, rapid, muscle, recovery, underlogging, adherence, compensation, water, rebound) each with evidence, counter-evidence, missing data, ranked causes and a confirming test. `decide()` walks the priority lattice — safety › data integrity › active experiment › adherence › rate of loss › performance › plateau › nutrition › training › activity › optimization — and returns one action with WHY / DO / REVERSE-IF / confidence / recheck / trace. Hold steady is a first-class result. Interventions become experiments with a stamped prediction; unsupported outcomes become negative knowledge that the lattice consults.

## Files (build order = `src/` sort order)
`00-head.html` tokens + stylesheet · `01-body.html` skeleton · `10-core` errors/dates/stats/units/formatting · `20-schema-storage` types, schema, migrations, validation, IndexedDB + localStorage, undo, memo · `30-observations` · `40-models` · `50-decision` (diagnosis, lattice, ledger, experiments, negative knowledge, learning, replay, snapshots, archive, VOI, schedule, programs) · `60-data-foundation` (generated) · `62-food` · `64-exercise` · `66-data-reference` · `70-demo` (generator + fixtures) · `80-ui` primitives · `82/83-views` · `85-log-sheet` sheets · `90-actions` dispatcher, palette, exports, PWA · `95-selftest` · `99-boot`.

## Invariants the self-test enforces
Schema validation and migration; correction/retraction semantics; sum-vs-mean aggregation and manual-over-food-log precedence; undo; statistics; e1RM; the 14 scenario fixtures and their expected decisions; epistemic rendering (predictive → lavender, measured never inferred); model registry completeness; decision field completeness; provenance + age on tiles; ledger stamped before outcome and immutable while pending; replay leakage = 0 and no mutation; hold steady on good data; snapshots/archive; negative knowledge redirecting a decision; an active experiment freezing lower levels; food search/scaling/snapshot immutability/retraction; exercise ontology; reference provenance; demo determinism and marking; every `data-act` registered; 12 views on a fixture and on an empty record without quarantined errors; keyboard focusability; every command runnable; accessibility audit; exports.

## Storage
`DB` is the single in-memory truth. `save()` bumps `revision`, mirrors to localStorage synchronously, queues IndexedDB (`physique-os/kv/db`). Boot paints from the mirror, then adopts the IndexedDB copy if newer. Daily auto-backups are written to IndexedDB; other tabs are detected through the storage event. Corrupt data is preserved raw and a fresh record is started with a corruption event in the ledger.

## Build
`node build.mjs` concatenates `src/` into `dist/index.html` (region-marked, no bundler, `eval`/`new Function`/`document.write` forbidden and asserted), writes `sw.js`, the manifest, icons and checksums. `node tests/run.mjs` boots the built file in jsdom, exercises views, sheets, dispatcher, palette, keyboard, persistence and exports, and runs the in-app self-test; non-zero exit on any failure. `scripts/food-build.mjs` streams the USDA Branded zip (never extracted) into positional shards with a delta-encoded inverted index and a GTIN index; raw USDA files are build inputs only.
